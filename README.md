# Kedai Laju

Landing page sederhana untuk restoran cepat saji Kedai Laju di Kota Rimbun.

## Menjalankan

Buka `index.html` langsung di browser. Proyek ini memakai HTML, CSS, dan JavaScript vanilla tanpa proses build.

## Isi proyek

- `index.html` — struktur halaman dan konten
- `styles.css` — tampilan responsif
- `script.js` — interaksi menu navigasi di layar kecil

## Catatan

Alamat, nomor WhatsApp, harga, dan beberapa gambar adalah contoh dan dapat diganti sesuai informasi restoran.
